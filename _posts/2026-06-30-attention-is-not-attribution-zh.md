聊多模态模型时我反复撞到一个说法：「回答越长，分给视觉 token 的注意力越低，所以模型越来越依赖语言先验、忽略了图像——幻觉就是这么来的。」

方向上没错。但这句话底下把两件不一样的事缝成了一件，缝口正好是别人一推就裂的地方。

## 两个机制，穿了同一件外套

「文本变长，视觉注意力下降」这句话，可能指两件事，而它们不是一回事。

**一是份额被摊薄了。** 注意力是 softmax，所有 token 的权重加起来恒等于 1。文本 token 多了，这些新 token 占掉一部分固定预算，留给视觉 token 的那块自然变小。这是个机械结果，不需要任何「模型偏爱语言」的故事。哪怕视觉 token 承载了全部有用信号，这件事照样发生——归一化只是把同一块饼切成了更多份。

**二是模型真的开始少依赖图像了。** 这才是有意思的命题：模型主动把计算挪向语言上下文，不再去查视觉证据。

人们说「视觉注意力下降」，让它同时代表这两件事。但你真正想证的只有第二件。第一件是 softmax 的副产品。如果你证明「模型忽略图像」的证据只是「视觉注意力份额降了」，那你证的是那件 trivial 的事，顺手把那件有意思的事白嫖进来了。

## 注意力分数高，不等于信息贡献大

更深的坑是：默认注意力权重能衡量信息贡献。

它经常不能。Transformer 里有 attention sink——大量注意力堆在第一个 token、分隔符、少数几个几乎不带语义的位置上。反过来,注意力分数**低**的 token 可能在干关键活。看清这件事的干净办法是把 token 敲掉：mask 掉视觉 token,或者 ablate 它,看输出怎么变。那些视觉 token 注意力分数平平无奇的模型,一旦把这些 token 拿走,输出照样崩——说明低分数从来不等于低重要性。

所以「视觉注意力很小」本身推不出「视觉信息没被用到」。注意力是模型在归一化记账意义上「看哪」,不是答案「依赖什么」的账本。这两者经常分家。

这是可解释性领域反复重学的一条通则的具体案例:**saliency 不是 causality。** 一张在某区域亮起来的热力图,告诉你模型在那里施加了注意力。它没告诉你,如果那个区域换掉,预测会不会变。能告诉你后者的只有干预——改输入,固定其余,量 delta。

## 不同层、不同头并不一致

笼统说法还抹掉了第三件事。「视觉注意力衰减」把整个网络当成均质的一坨,但注意力行为在层与层、头与头之间差别极大。通常是少数浅层和几个专门的头在真做跨模态对齐,深层大多在聚合文本。如果你把整个 stack 的注意力平均了再宣布「模型不看图了」,你就把那些本来就没在看的头和真在看的头糊到了一起——少数关键的被多数无关的淹没。

## 而且因果箭头没标方向

就算承认长输出里视觉依赖确实下降了,箭头朝哪边?

- *回答长 → 视觉注意力被稀释 → 幻觉*,还是
- *模型本来就要编(语言先验主导)→ 于是生成了又长又脱离图像的回答*?

观察到的只是「长输出和弱视觉接地相关」,这跟两种解释都兼容。它们对应的修法完全不同。第一种说「生成到一半时把视觉注意力重新注入」。第二种说「问题在变长之前就开始了,长度只是症状」。光靠相关性你没法二选一,你需要一个干预——操纵其中一个,看另一个动不动。

## 怎么说才经得起推

把原来的话拆开:机械的那部分归机械,依赖的那部分用干预实验兜,而不是用可视化。

> 随着生成变长,视觉 token 的注意力**份额**被增长的文本上下文摊薄(softmax 归一化效应,叠加 attention decay)。另外,visual token knockout 实验显示,长回答后段对图像的**实际依赖**也在下降。两者叠加,把后段推理推离图像、推向语言先验,抬高幻觉风险。

这版把 trivial 的效应说成 trivial,把真效应说成一个量出来的依赖,再用实验而不是热力图去补那道因果的缝。结论一样,只是没人一推就倒。

## 能带走的那条

每当你发现自己在把一个权重——注意力、梯度幅值、特征重要性的柱子——当成模型「用了」或「忽略了」某个输入的证据时,停一下,问自己量的是「看」还是「依赖」。它俩感觉像一回事,其实不是。便宜的那个量,一次前向就附赠,还能渲染成好看的图。真的那个要花你一次 ablation:把输入打断,固定其余,看答案在不在乎。

你要是没打断任何东西,你手上就没有因果命题。你手上是一张热力图。
