花点时间去给一个 coding agent 做实时视图——那种能让你看到它此刻在调什么工具、在想什么、上下文还剩多少的东西——你会撞上一个跟界面毫无关系的问题。它是一个披着工程外衣的认识论问题：要看清这东西在干什么，你就得相对它站在某个位置上，而你站在哪，同时决定了你能看多少、又扰动了多少。不存在一个既能看到全部、又什么都不碰的观察点。

我最后把这些做法归成了四种，它们恰好落在同一根轴上。

## 观察的四种姿势

**读痕迹。** Agent 跑的时候会往磁盘写东西——session 日志、transcript、一份记录发生了什么的 JSONL。你从外面轮询这些文件。你是纯粹的旁观者，什么都不改。但你只能看到 agent 主动写下来的那部分，而且是它写完之后才看到；一个 turn 结束了，你才知道它发生过。这是在一个还活着的挖掘现场做考古。这种做法有个一眼可辨的特征：有些字段就是缺的——token 数、模型名、还剩多少上下文——因为 agent 从来没有理由把它们落盘。

**装钩子。** 大多数 agent 运行时都有回调点：工具执行前、权限请求时、一个 turn 结束时。你注册进去。现在你拿到的是事件发生的当下、而不是事后，而且是结构化的。代价是你已经在 agent 的执行流程*里面*了——你的回调跑在它的循环里，一旦你的 handler 慢了或抛了异常，你就不再只是「看」了，你变成了一个能把这次运行搞崩的东西。而且钩子只在运行时决定放的地方触发，所以你的视野完整到别人画的那条边界为止，一分不多。

**接管 I/O。** 把 agent 作为子进程启动，接管它的 stdin 和 stdout，直接说它的流式协议。这时候完整度陡然上一个台阶：因为你读的是 agent *专门为此目的*吐出的官方事件流，那些磁盘痕迹里缺的字段——模型、token 用量、上下文百分比——突然就稳定拿得到了，因为 agent 是在*告诉*你，而不是留下一串要你去解读的脚印。但看看你为此付出了什么。你已经不是在观察这个 agent 了。你是那个启动它、喂它、读它的进程。它是在你的许可下运行的。观察者变成了操作者。

**成为它。** 最后一种根本不是观察。你不去给别人的 agent 装仪表；你自己就是 agent 的作者，循环是你的，每一个中间状态都是一个本地变量。完全的可见性，零解读。当然，也是零间隔——不再有「那个 agent」和「那个观察者」之分了。你把想观察的东西扔了，换成了你自己。

## 标签上没写的那根轴

读痕迹 → 装钩子 → 接管 I/O → 成为它。沿着这条线，有两样东西一起往上走，而且是出于同一个原因一起往上走。侵入度在涨：你从什么都不碰，到在循环里跑代码，到控制这个进程，到成为这个进程。完整度也在涨：从「凡是落盘的」到「每一个内部状态」。它们一起爬，因为这本来就是同一个动作的两个侧面。要弥合「系统上报的」和「它实际做的」之间那道缝，唯一的办法就是靠近「做」发生的地方——而每靠近一步，都是从观察者往参与者迈的一步。

这不是 coding agent 独有的。这是你去给任何一个自己并不完全拥有的自主进程装仪表时，都会呈现的形状。给程序做性能分析：从外面采样，便宜且有损；给二进制插桩，精确、却改变了你本想测量的那个时序。研究一个组织：读会议纪要，安全而肤浅；坐进会议室，你就成了这场会议的一部分。盯一个市场：行情是公开的、滞后的；成为做市商，每一笔订单都到你手里，而你的存在本身会推动价格。就连物理里也有这件事的礼貌版本——你没法测量那个小东西，而不让测量本身成为一次相互作用。

## 为什么「把这根轴说出来」很重要

实践中的错误，是为了一个并非真实代价的理由去挑范式。你伸手去用钩子，因为它「加起来简单」，于是没意识到你已经签下了「在一个你并不控制的循环里跑代码」这份合同——直到某个慢 handler 卡住了 agent。你伸手去读痕迹，因为它「无侵入」，于是发布了一个悄悄报错上下文百分比的仪表盘，因为那个数字从来没落过盘，你一直在插值猜。每一级都有一个从下一级看不见的失败模式，而这个失败模式，永远是你没承认自己揽下的那份侵入、或是你以为自己有其实没有的那份完整。

所以诚实的选法，是把这笔交易说出来。如果你绝对不能扰动这东西——它是生产环境、它是别人的、卡一下都不可接受——那你就待在轴的低处，并且*接受一个有损、滞后的视图*作为代价，别让任何人从一个你在猜的字段上读出一个笃定的数字。如果你需要完整的画面——每一个 token、真实的上下文预算、确切的停止原因——那你就接受你已经爬向了操作者那一端，并且认领「在循环里跑」所带来的那些失败模式。你唯一不能做的，是既想要「接管 I/O」的完整、又想要「读一个日志文件」的清白。那个观察点不在这根轴上。什么都不在。

观察一个系统和操纵一个系统，不是两件你能各自独立拧的事。它们是同一根轴；而每一个诚实的观察者，最终都会发现自己这一路究竟站在了它的哪一格上。
